# COLDER: A Blender-based Synthetic SfM/BA Dataset Generator

COLDER is a Blender-based tool that turns any 3D scene into a controlled Structure-from-Motion
dataset with exact ground truth: cameras, 6-DoF poses, 3D landmarks, 2D observations,
depth maps, and covisibility, exported directly in [COLMAP format](https://colmap.github.io/format.html).
It provides a simple blender panel for quick dataset generation, as well as a command-line interface for headless operation and batch generation.

![COLDER overview](.docs/images/colder.png)

It was built to study initialization-free bundle adjustment (InitFree BA) for the TPAMI submission:

> **Initialization-Free Bundle Adjustment Revisited: A Controlled Experimental Study**
> Simon Weber\*, Mateo de Mayo\*, Je Hyeong Hong, Carl Olsson, Daniel Cremers, Ronald Clark

Real-world SfM benchmarks offer no control over camera trajectories, observation density, or
initialization conditions, and no ground truth for intermediate (non-optimized) reconstruction
states. COLDER solves this by rendering synthetic (or photorealistic) scenes in Blender with
fully known camera geometry, letting researchers isolate exactly which factors (initialization
priors, landmark density, metric-upgrade stability, robustification, ...) cause an InitFree BA
pipeline to succeed or fail. The companion C++ evaluation framework that consumes datasets
generated by this tool is available at
[github.com/simonwebertum/InitFreeBA](https://github.com/simonwebertum/InitFreeBA).

## What it exports

For each generated sequence, COLDER produces:

- **Cameras**: intrinsics (COLMAP `SIMPLE_RADIAL` model) and ground-truth extrinsics per frame
- **Landmarks**: 3D points sampled from the scene, with configurable density
- **Observations**: 2D projections of landmarks per camera, with optional occlusion handling
- **Depth maps**: per-camera dense/sparse depth, with a debug visualization mode
- **Covisibility**: which cameras share observations of which landmarks
- **RGB renders**: via Blender's EEVEE realtime rendering engine, for synthetic or photorealistic scenes

Everything is written directly in COLMAP-compatible format for immediate use with existing and
future SfM/BA pipelines. Optional Gaussian noise can be injected into 2D/3D points and poses to
simulate imperfect real-world data.

## Setup

Requires [uv](https://docs.astral.sh/uv/) and a [Blender](https://www.blender.org/) installation.

```bash
uv sync
uv run python cli.py setup_blender  # Installs COLDER's dependencies into Blender's Python environment
```

## CLI Usage

```bash
uv run python cli.py generate main.blend configs/default.json
```

This opens `main.blend` headlessly in Blender, runs the exporter with the given config, and
writes the dataset to the `EXPORT_PATH` specified in the config (see
[configs/default.json](configs/default.json) for all available options: point/observation
density, minimum observations per landmark, noise levels, depth/RGB/COLMAP export toggles, etc).

## Blender UI Usage

COLDER also ships as an in-Blender panel (**COLDER Tools**), with operators to:

- `Spawn Cameras`: place cameras around paths in the scene
- `Spawn Cameras from Anim`: bake cameras along an existing animated camera path
- `Apply Look-At`: apply spawned cameras orientation towards a look-at target
- `Export Scene` / `Render Depthmaps` / `Render Images` / `Generate All`: run the
  export pipeline (or its individual stages) from the UI
- `Clear Cameras`: remove spawned cameras

## Creating a realistic dataset

This workflow is manual for now, but works well for photorealistic sequences and it is easy to automatize in the future. The steps are:

1. Get a good model, e.g. from [Sketchfab](https://sketchfab.com/) or the BlenderKit addon.
2. Create a single camera and use `Spawn Cameras` once so all intrinsics are generated.
3. Add an HDRI if the scene doesn't have one: Shading workspace / World shader / Add
   Environment Texture.
4. Walk around the scene with the camera while recording (red record button, then Space to
   play the animation).
5. Optional: for handheld realism, open the Graph Editor, select the camera's XYZ/rotation
   channels, and add noise modifiers to each.
6. Press `Spawn Cameras from Anim` to bake a camera per recorded frame.
7. Run `Generate All` in the Blender UI, or `cli.py generate` from the command line.
